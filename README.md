# 波-神经元自统一神经网络 (Wave-Neuron Self-Unifying Neural Network)

> 一个基于预测编码与自组织结构的脉冲神经网络（SNN）框架。

---

## 核心思路

本框架将**智能**定义为：系统在持续时间流中，为最小化自身预测误差而进行的在线状态调整与结构重塑。

系统摒弃预设的固定拓扑与全局优化目标，所有宏观秩序均从微观局部交互中自然涌现。

系统采用「输入面 → 神经网络 → 输出面」的三层结构：

1. **输入面 (Face1)**：接收物理信号（像素 RGB 值等），作为神经元的输入电流
2. **三维神经网络**：由积分-放电（IF）神经元构成，初始位置基于真实星图数据分布以获得天然的类人脑结构
3. **输出面 (Face2)**：输出对下一时刻输入的预测值

所有模态在物理层统一为"随时间的数值变化"——视觉是像素值的时序变化，听觉是频段声强的时序变化，触觉是传感器压强的时序变化。

## 学习机制

每个时间步执行完整的"预测-误差-修正"循环：

| 机制 | 作用 |
|------|------|
| 正向 STDP | 前神经元先放电、后神经元后放电 → 权重增强（因果学习） |
| 反向误差 STDP | 误差波反向传播，预测偏低增强、偏高削弱 |
| 阈值自适应 | 误差 > 0 降低阈值（提高灵敏度），反之升高 |
| 结构可塑性 | 活跃神经元间通过"探测波"生成或修剪连接 |

## 训练与推理分阶段

- **训练阶段**：结构可塑性开放，允许探测波空间搜索、连接生成与修剪，类似"睡眠"
- **推理阶段**：拓扑冻结，仅允许权重微调与阈值调节，类似"清醒"，低功耗实时运行

## 一、核心脉冲引擎

### 1. 网络空间结构

引擎是一个具有三维空间坐标的脉冲神经网络，分为三个功能区域：

- **第一面（输入面）** ：接收外部注入的模拟信号。
- **第二面（输出面）** ：对外输出预测结果，并接收外部反馈的误差偏置。
- **中间神经网络**：位于两面之间的三维神经元场。

中间层神经元的初始空间位置来源于宇宙大尺度星图（星系团分布）的坐标缩放。这种初始化方式使网络天然同时具备：
- **局部聚集性**：形成有序柱状结构。
- **全局散落性**：存在无序背景，避免随机初始化的空洞和规则网格的过度对称。

每个神经元拥有固定的**连接半径**，超出该半径的神经元之间不具备建立突触连接的条件。

### 2. 神经元模型

每个神经元采用积分放电模型的变体，核心规则如下：

- **积分**：膜电位持续累积来自外部输入和其他神经元的脉冲输入。
- **放电与减法重置**：当膜电位达到当前放电阈值时，神经元发放脉冲，随后膜电位直接**减去当前阈值**，剩余差值保留为下一轮积分的起点。这种重置方式保留了神经元的惯性，同时天然形成放电后的绝对不应期。
- **动态阈值**：每个神经元的放电阈值并非固定常数，而是根据该神经元过去一段时间内膜电位的滑动窗口平均值实时动态调整。神经元活跃时阈值自适应抬高，沉寂时阈值降低，从而维持网络整体的发放率稳态。

### 3. 时间步的定义

一个**时间步** = 扫描指针完成一次对所有神经元的完整遍历（即一轮全空间扫描）。

每一轮扫描中，每个神经元恰好被访问一次，执行一次状态更新。该时间步是引擎内部最基本的时间单位，所有可塑性规则（STDP、动态阈值、睡眠期的结构统计）均基于此进行计数和计算。

### 4. 引擎的基础运行机制

引擎内部维持一个**永不停止的扫描指针**，按照三维空间顺序巡回访问所有神经元。这个扫描过程是引擎最底层的运行机制，在清醒态和睡眠态中持续无差别地运转，不受外部状态切换的影响。

每当扫描指针访问到某个神经元时，该神经元执行以下操作：

1. 将外部注入该位置的模拟信号（如有）直接叠加到膜电位上；
2. 将从其他神经元发来的、已在缓存中等待的脉冲电荷累加到膜电位上；
3. 判断膜电位是否达到当前阈值：
   - 若达到，发放脉冲，将脉冲按连接权重放入全局缓存队列（等待后续扫描到目标神经元时传递），随后执行减法重置；
   - 若未达到，仅做积分，不动作；
4. 根据更新后的膜电位，刷新该神经元的滑动窗口平均值，并调整其动态阈值。

**脉冲传导采用单步延迟**：脉冲在当前神经元发放后，不立刻作用于目标，而是暂存于缓存池，等待扫描指针在同一轮扫描的后续行程中或下一轮扫描到达目标神经元时再施加。该过程构成完整的一个时间步。

### 5. 清醒态 (Wake State)

在此状态下，引擎执行以下操作：

- **基础扫描与脉冲传导**：扫描器持续运行，所有神经元按上述操作正常更新。
- **STDP（脉冲时间依赖可塑性）** ：每对前后发放的神经元，根据它们放电的时间差，实时调整两者之间已有突触连接的权重。
- **动态阈值更新**：每个神经元的放电阈值随其膜电位滑动窗口持续自适应调节。

清醒态**不涉及连接的生成和剪枝**。已有连接的权重可以变化，但不会生成新连接，也不会删除旧连接。

### 6. 睡眠态 (Sleep State)

进入睡眠后，引擎的基础扫描与脉冲传导机制**完全不变**——扫描指针仍然在三维空间中巡回，神经元依然正常积分、放电、传递脉冲，STDP也持续生效，连接权重仍在调整。

睡眠态与清醒态的唯一区别在于**增加了结构可塑性操作**：

- **生长新连接**：对于满足连接半径条件且符合共同放电规律（Hebb痕迹）的神经元对，生成新的突触连接。新连接的初始权重设为一个较小的正值。
- **剪枝冗余连接**：遍历现有连接表，删除那些权重已衰减至接近于零的冗余连接。

简言之：

- **清醒态 = 基础扫描 + STDP（权重调节）+ 动态阈值**
- **睡眠态 = 基础扫描 + STDP（权重调节）+ 动态阈值 + 结构生长与剪枝**

两者的底层计算框架完全相同，睡眠仅是在其之上开启了额外的结构重塑性操作。

### 7. 引擎的标准化整面接口

引擎对外提供以下标准交互方式：

- **向第一面传入信号**：外部系统将一整面模拟强度图（每个值在 -1 到 1 之间）一次性注入第一面的所有神经元。每个位置的强度值直接叠加到对应神经元的当前膜电位上。
- **从第二面读取输出**：外部系统一次性读取第二面所有神经元的当前实时膜电位值（连续标量），作为网络对当前输入的综合预测输出。
- **向第二面注入误差偏置**：外部系统将计算得到的误差信号（同样为 -1 到 1 的整面强度图）一次性注入第二面所有神经元，作为调制偏置直接叠加到其膜电位上。正值起兴奋作用，负值起抑制作用。

引擎内部不设"收敛判定"或"步长等待"。外部系统按照自身的采样频率随时进行整面读写，引擎始终在后台持续运行其永恒扫描进程。

### 8. 睡眠态的触发与退出

睡眠态的进入和退出均由**外部程序手动控制**，暂不内置自动触发策略。睡眠时长的设定（即睡眠阶段持续多少个时间步）亦留待实验研究确定。接口层面仅提供"进入睡眠"和"退出睡眠"的切换控制，不预设具体参数。

## 二、外围交互回路（引擎外部应用层）

引擎本身不关心信号的具体物理含义。所有感官编码、误差计算和执行器驱动均在引擎外部实现，通过上述整面接口与引擎交互。

### 1. 感官编码

各类物理信号在外部被编码为 -1~1 的强度图：

- **视觉**：将图像拆分为 RGB 三个通道，每个像素对应第一面的一个神经元位置，传入该像素对应颜色通道的归一化强度。
- **听觉**：对音频信号进行频谱分解，将各频段的能量强度映射至 -1~1，传入第一面对应位置的神经元。
- **触觉**：将各触觉感受器（压力、温度、振动等）的物理读数线性映射至 -1~1，传入第一面相应位置的神经元。

### 2. 预测误差闭环

外部主控程序按照固定的采样周期运行以下循环：

1. 将当前时刻的真实感官输入注入第一面；
2. 让引擎运行若干个时间步（一轮或多轮完整扫描）；
3. 从第二面读取当前的预测输出膜电位；
4. 获取下一时刻的真实感官输入，将两者逐位置相减，得到误差强度图（值域仍在 -1~1 内）；
5. 将该误差图作为反向偏置，一次性注入第二面；
6. 将当前时刻的真实输入再次注入第一面，进入下一轮循环。

误差以模拟量直接回传，无需进行脉冲编码，因为引擎的接口原生接受 -1~1 的连续模拟值。

### 3. 动作执行扩展

在网络的第二面，可选取若干**不参与误差回传**的神经元作为动作神经元。外部系统读取这些神经元的放电，将其映射为机械臂的移动等控制指令。

这些动作神经元本身不直接接收误差偏置，但它们输出的动作会改变外部物理环境，进而影响下一时刻传入第一面的感官信号，因此通过外部物理世界间接形成了完整的闭环控制回路。

## 三、总结

| 维度 | 设计特点 |
|------|----------|
| 网络结构 | 三维坐标空间，星图初始化，固定连接半径 |
| 神经元模型 | 积分-放电，减法重置，动态阈值 |
| 时间驱动 | 固定扫描指针，单步延迟传导 |
| 清醒态 | STDP + 动态阈值，拓扑冻结 |
| 睡眠态 | 清醒态基础 + 结构生长与剪枝 |
| 外部接口 | 整面模拟信号注入与读取，连续值传递 |
| 学习闭环 | 预测 → 读取真实 → 计算误差 → 误差回传 |
| 动作扩展 | 第二面动作神经元，通过物理世界间接闭环 |
