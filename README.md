# 波-神经元自统一神经网络 (Wave-Neuron Self-Unifying Neural Network)

> 一个基于预测编码与自组织结构的脉冲神经网络（SNN）框架。

---

## 核心思路

本框架将**智能**定义为：系统在持续时间流中，为最小化自身预测误差而进行的在线状态调整与结构重塑。

系统摒弃预设的固定拓扑与全局优化目标，所有宏观秩序均从微观局部交互中自然涌现。

## 架构概览

系统采用「输入面 → 神经网络 → 输出面」的三层结构：

1. **输入面 (Face1)**：接收物理信号（像素 RGB 值等），作为神经元的输入电流
2. **三维神经网络**：由积分-放电（IF）神经元构成，初始位置基于真实星图数据分布以获得天然的类人脑结构
3. **输出面 (Face2)**：输出对下一时刻输入的预测值

所有模态在物理层统一为"随时间的数值变化"——视觉是像素值的时序变化，听觉是频段声强的时序变化，触觉是传感器压强的时序变化。

## 学习机制

每个时间步执行完整的"预测-误差-修正"循环：

| 机制 | 作用 |
|------|------|
| 正向 STDP | 前神经元先放电、后神经元后放电 → 权重增强（因果学习） |
| 反向误差 STDP | 误差波反向传播，预测偏低增强、偏高削弱 |
| 阈值自适应 | 误差 > 0 降低阈值（提高灵敏度），反之升高 |
| 结构可塑性 | 活跃神经元间通过"探测波"生成或修剪连接 |

## 训练与推理分阶段

- **训练阶段**：结构可塑性开放，允许探测波空间搜索、连接生成与修剪，类似"睡眠"
- **推理阶段**：拓扑冻结，仅允许权重微调与阈值调节，类似"清醒"，低功耗实时运行
