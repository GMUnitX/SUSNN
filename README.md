# 波-神经元自统一神经网络 (Wave-Neuron Self-Unifying Neural Network)

> 一个基于预测编码与自组织结构的脉冲神经网络（SNN）框架，无需针对视网膜做特异性设计，即可自然涌现光适应、色偏、永久性暗点、运动预测等视网膜核心特征。

---

## 核心思路

本框架将**智能**定义为：系统在持续时间流中，为最小化自身预测误差而进行的在线状态调整与结构重塑。

系统摒弃预设的固定拓扑与全局优化目标，所有宏观秩序均从微观局部交互中自然涌现。其核心哲学可概括为三条原则：

- **结构即知识** — 网络拓扑不是预设的，而是在数据驱动下自组织生成的
- **连接即涌现** — 宏观功能从微观突触的局部竞争与协作中涌现
- **学习即运行** — 每个时间步都在学习和预测，摒弃离线训练与推理的严格界限

## 架构概览

系统采用「输入面 → 神经网络 → 输出面」的三层结构：

1. **输入面 (Face1)**：接收物理信号（像素 RGB 值等），作为神经元的输入电流
2. **三维神经网络**：由积分-放电（IF）神经元构成，位置基于真实星图数据分布
3. **输出面 (Face2)**：输出对下一时刻输入的预测值

所有模态在物理层统一为"随时间的数值变化"——视觉是像素值的时序变化，听觉是频段声强的时序变化，触觉是传感器压强的时序变化。

## 学习机制

每个时间步执行完整的"预测-误差-修正"循环：

| 机制 | 作用 |
|------|------|
| 正向 STDP | 前神经元先放电、后神经元后放电 → 权重增强（因果学习） |
| 反向误差 STDP | 误差波反向传播，预测偏低增强、偏高削弱 |
| 阈值自适应 | 误差 > 0 降低阈值（提高灵敏度），反之升高 |
| 结构可塑性 | 活跃神经元间通过"探测波"生成或修剪连接 |

## 训练与推理分阶段

- **训练阶段**：结构可塑性开放，允许探测波空间搜索、连接生成与修剪，类似"睡眠"
- **推理阶段**：拓扑冻结，仅允许权重微调与阈值调节，类似"清醒"，低功耗实时运行

## 实验验证

### 实验 1：强光损伤与恢复
对中心区域施加周期性强光刺激，观察到：
- 连接数从 ~2,500 爆发至 18,000+
- 损伤区域阈值持续下降，形成不可逆的"阈值疤痕"
- 永久性暗点：阈值逼近下限形成"吸收态"吸引子，即使停止强光也无法恢复

### 实验 2：运动预测
白色方块在黑色背景上匀速移动，观察到：
- 平均预测误差下降约 8%，网络习得了运动规律
- 最大误差始终出现在运动物体前沿，证明网络学会了预测"将要"出现的位置

## 关键发现

本框架在没有针对视网膜做任何特异性设计的情况下，自然涌现了以下视网膜核心特征：

- **光适应/暗适应** — 阈值自适应机制实现灵敏度动态调节
- **色偏与永久性暗点** — 持续强光导致阈值压至下限，形成吸收态吸引子
- **马赫带（边缘增强）** — 三维空间邻近连接竞争产生等效侧向抑制
- **运动预测** — STDP 时间不对称性使网络学习时空关联
- **颤动抑制** — STDP 时间窗的积分效应
